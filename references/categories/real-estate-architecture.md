# Emlak / Gayrimenkul / Mimarlık / İç Mimarlık / İnşaat Projesi

Kapsam: emlak ofisi/portal, proje tanıtımı (konut/rezidans), mimarlık ofisi, iç
mimarlık stüdyosu, mobilya/dekorasyon. ThemeForest: Velux (emlak), Archidex,
Framehaus, Terris (mimarlık portfolyosu), AVAVA Motors'a benzer ilan/filtre yapısı,
Crafto "Interior Design" demosu, Structo (inşaat; corporate ile kesişir).

İki ayrı dünya:
- **Emlak/portal**: ilan arama, filtre, harita, karşılaştırma → netlik ve güven.
- **Mimarlık/iç mimarlık**: portfolyo mantığı (creative-portfolio.md'yi de oku) →
  sükûnet, malzeme, ışık.
- **Proje tanıtımı (tek konut projesi)**: tören/lüks tonu (hospitality'ye yakın) →
  aidiyet arzusu ("burada yaşamak").

## Ziyaretçi hali → hedef duygu
Emlak: hayatının en büyük kararını veriyor, tedirgin ve karşılaştırıyor → **güven +
"istediğimi hızlı bulurum"**. Mimarlık: işveren ya da meslektaş, zevk ve yetkinlik
arıyor → **saygı + merak**. Proje: "burada yaşıyor olsam" hayali → **aidiyet**.

## Anasayfa bölüm sırası
Emlak: hero + arama formu (konum, tip, fiyat, oda) → öne çıkan ilanlar → kategoriler
(satılık/kiralık/ticari) → neden biz → danışmanlar → yorumlar → blog/rehber → CTA.
İlan kartı: fotoğraf, fiyat, konum, m², oda, banyo; detay sayfası galeri + harita +
özellikler + danışman iletişim.

Mimarlık: tam genişlik proje görseli hero → seçili projeler (büyük, az) → stüdyo
hakkında → hizmetler (kısa) → ekip → yayın/ödül → iletişim.

Proje tanıtımı: sinematik hero → konum/ulaşım → kat planları → olanaklar → galeri/
render → teslim takvimi → bilgi formu.

## Görsel dil
- **Sıcaklık**: emlak → güven mavisi/yeşili yaygın; alternatif tuğla, kum, şehir
  grisi. Mimarlık → nötr: beyaz/siyah/beton, rengi malzeme verir (meşe, bakır,
  mermer). Proje → lüks kömür + bej/altın ya da projenin kendi malzemesi.
- **Ağırlık**: emlakta okunaklı grotesk + büyük rakamlar (fiyat, m²); mimarlıkta ince,
  geniş aralıklı; projede serif display.
- **Tempo**: emlak bilgi yoğun ama ızgaralı; mimarlık çok geniş; proje yavaş.
- **Doku**: emlak → gerçek daire fotoğrafı, harita; mimarlık → tam genişlik mimari
  fotoğraf, çizim/plan; proje → render + malzeme yakın çekimi.
- **Hareket**: emlakta filtre/harita etkileşimi asıl hareket; mimarlıkta yavaş
  reveal; projede sinematik tek an.
- **Ses**: emlakta somut rakam ve konum; mimarlıkta az ve kesin; projede davet.

## Tipik alt sayfalar
Emlak: ilanlar (liste/ızgara/harita), ilan detayı, danışmanlar, hakkımızda, blog,
iletişim, ilan ver. Mimarlık: projeler + detay (künye: yer, yıl, m², işveren),
stüdyo, ekip, yayınlar, iletişim. Proje: kat planları, konum, galeri, olanaklar,
iletişim/bilgi formu.

Projeleri gör

## İçeriğe yakınlık ipuçları
- Emlakta güven **veri şeffaflığından** gelir: fiyat, m², kat, yaş, aidat görünür;
  "Fiyat sorunuz" güven kırar.
- Mimarlık ofisinin dili yaptığı binaya benzesin: brütalist ofis → sert ızgara, ince
  çizgi; ahşap ağırlıklı ofis → sıcak nötr, yumuşak ışık.
- Proje tanıtımında kat planı ve konum, renderdan daha çok güven verir; ikisini de
  koy ama planı ulaşılır yap.
- Hatırlanacak an: emlakta harita + liste bölünmüş görünüm; mimarlıkta tek tam
  ekran proje; projede gün batımı renderı + tek satır.

## Kaçın
Stok anahtar teslimi/el sıkışma; mavi gradient; mimarlıkta kartlar ve ikonlar;
projede "hayalinizdeki yaşam" klişe başlığı; sahte "son 3 daire" aciliyeti.
