# Düğün / Davet / Doğum Günü / Konferans / Etkinlik / Bilet

Kapsam: çift davetiye sitesi, düğün planlayıcı/organizasyon firması, doğum günü/
sünnet/nişan daveti, konferans/zirve/meetup, festival, bilet/sinema. ThemeForest
Wedding: Belle (14 renk şeması), Royal Love, Florya (planner; Dark/Light × Onepage/
Multipage), Muhibbi (18 home, Hint/İslami düğün, RSVP yönetimi). Entertainment/
Events: Eventen (Poppins), Boleto (bilet/koltuk planı).

İki ayrı tür:
- **Davetiye (çift)**: tek sayfa, tören duygusu, RSVP.
- **Planlayıcı/organizasyon firması**: hizmet sitesi (creative-portfolio +
  corporate karışımı) → zarafet + "her şey kontrolümüzde".
- **Konferans/etkinlik**: program, konuşmacılar, bilet → aciliyet + prestij.

## Ziyaretçi hali → hedef duygu
Davetiye: davetli, mutlu, meraklı, "ne zaman nerede, ne giyeyim, nasıl giderim?"
→ **mutluluğa ortak olma + pratik netlik**. Planlayıcı: çift, heyecanlı ve
stresli → **"rahatlayabilirim, bunlar halleder"**. Konferans: profesyonel,
zaman kısıtlı → **"burada olmalıyım" + hızlı kayıt**.

## Anasayfa bölüm sırası
Davetiye: tam ekran çift fotoğrafı + isimler + tarih (script/serif) → geri sayım →
hikâyemiz → program (nikâh/yemek: saat, mekân, harita) → galeri → nedime/sağdıç
(ops.) → RSVP formu → hediye/kayıt listesi (ops.) → footer (hashtag, sosyal).

Planlayıcı: slayt/video hero → hakkında → hizmetler → portfolyo (gerçek düğünler)
→ paketler/fiyat → yorumlar → ekip → blog → iletişim/teklif.

Konferans: hero (etkinlik adı, tarih, yer, geri sayım, "bilet al") → hakkında/
tema → konuşmacılar ızgarası → program sekmeli (gün/salon) → bilet seviyeleri →
sponsorlar → mekân/ulaşım → SSS → kayıt.

## Görsel dil
- **Sıcaklık**: düğün → krem/fildişi/toz pembe/adaçayı + altın; koyu lüks varyant
  (siyah + altın). Doğum günü/sünnet → neşeli pastel ya da doygun. Konferans →
  temiz kurumsal + bir canlı vurgu; teknoloji konferansında koyu mod.
- **Ağırlık**: düğünde script ya da yüksek kontrastlı serif + ince sans; harf
  aralığı geniş; script yalnız isim/başlıkta. Konferansta kalın geometrik sans
  (Poppins türü), büyük tarih rakamları.
- **Tempo**: düğün çok yavaş, merkez hizalı meşru; konferans hızlı, bilgi yoğun.
- **Doku**: düğün → kâğıt, çiçek, ipek, film grain, ince çizgi süs; konferans →
  sahne fotoğrafı, konuşmacı portreleri, logo ızgarası.
- **Hareket**: geri sayım ikisinde de imza; düğünde yavaş fade/parallax; konferansta
  sekme geçişleri, marquee sponsor.
- **Ses**: düğün davet dili, kısa, sıcak; konferans emir kipi + somut ("3 gün, 40
  konuşmacı"), erken kayıt indirimi.

## Tipik alt sayfalar
Davetiye genelde tek sayfa (+ RSVP teşekkür). Planlayıcı: hizmetler, portfolyo +
detay, paketler, blog, iletişim. Konferans: konuşmacılar + profil, program, bilet,
mekân, sponsor ol, geçmiş yıllar, blog.

## İçeriğe yakınlık ipuçları
- Davetiyede pratik bilgi (saat, adres, harita, otopark, kıyafet kodu) estetik kadar
  önemli; davetli mobilde yolda bakar → yapışkan "Yol tarifi".
- Çiftin kimliği paleti versin: kır düğünü → saman/adaçayı; şehir çatı → siyah/
  altın; sahil → kum/mavi. "Toz pembe + script" varsayılan olmasın.
- Konferansta program tablosu gerçek saatlerle ve konuşmacı adlarıyla; "Speaker
  Name" yazma, konuya uygun gerçekçi isim/unvan üret.
- Hatırlanacak an: düğünde isimler + tarih kompozisyonu (tipografik); konferansta
  geri sayım + sahne fotoğrafı hero.

## Kaçın
Çiçek çerçeve + script her yerde; geri sayım bittikten sonra kalan sayaç; 8 alanlı
RSVP; konferansta sahte sponsor logoları; "Save the date" tek başına içeriksiz hero.
