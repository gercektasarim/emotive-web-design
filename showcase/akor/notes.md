# Akor — tasarım notları

**Fiziksel dünya:** Dolabın üstünden inen tozlu, sunburst cilalı akustik gitar; gül ağacı klavye, kemik eşik, paslanmış teller; spiral defterdeki el çizimi akor kutuları; 70'ler Anadolu rock afişlerinin kalın slab harfleri; sahnede bantla yapıştırılmış set listesi; bir köşede bağlama.
**Geliş → çıkış:** Gençken bıraktığı gitarı 40'ında yeniden eline alan, parmakları sızlayan ve biraz utanan kişi → ilk akorları temiz çıkarmış, dört haftalık listesi olan, "yeniden çalıyor".

## Taslaklar
**A. Sunburst sahne** — kenar #3A120B, kızıl #8E3214, amber #E39B3A (sunburst cilası), kemik #F2E6D0, klavye #1C1210, tel #C9C2B6. Alfa Slab One (70'ler afiş/albüm kapağı) + Figtree (sıcak, okunur gövde). Hızlı-orta tempo, büyük başlık, kalın biçimler. Hero: ortalanmış afiş başlığı, sunburst zemin, tam genişlik gitar klavyesi; akor seç → parmak yerleri; "Çal" → teller titrer, boğuk tel turuncu yanar ve nedeni söylenir; tempo kaydırıcısı. Ses: "Parmaklar hatırlar. Sadece biraz zaman ister." Sıra: klavye → dört haftalık dönüş listesi + akor kutuları → bağlama → kimse duymasın → kızıyla söz → fiyat → SSS.
**B. Akor defteri** — spiral defter, kurşun kalemle çizilmiş akor kutuları, nostalji; Ötüş'ün defter diliyle çakışıyor ve "çalma" enerjisi düşük.
**C. Gece kulübü** — koyu zemin, neon tek vurgu, sahne ışığı; eğlence kategorisinin varsayılanı, kırk yaşındaki dönüş hikâyesine yabancı.
