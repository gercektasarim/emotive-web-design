# Ekşi Maya — tasarım notları

**Fiziksel dünya:** Tezgâhta düz kenarlı cam kavanoz, başlangıç seviyesine yapıştırılmış kâğıt bant, hedefi gösteren kırmızı lastik, çavdar unu, sabah ışığı.

**Giriş → çıkış:** İlk ekşi mayası üç kez ölmüş, kendine güveni kalmamış ev fırıncısı → zanaatkâr: mayanın huyunu biliyor, zirveyi kaçırmıyor.

## Yön taslakları

### A · Cam kavanoz ve bant
- **dünya:** cam kavanoz, kâğıt bant, lastik, çavdar
- **palet:** #E2E9E5 kavanoz camı · #2C241E çavdar · #D9CDB8 maya · #C92F2A lastik bant · #E9DCAE kâğıt bant · #3E6A57 adaçayı
- **tipografi:** Instrument Sans (dar genişlikte başlık: fırıncının defter başlığı gibi) + Caveat (bantlara keçeli kalem)
- **tempo:** orta; geniş başlık, sakin bölümler
- **doku:** cam yansıması, kabarcıklar, bant şeritleri
- **hareket:** süre kaydırıcısı ve sıcaklıkla kavanozun kabarması
- **ses:** teşhis koyan usta: 'Maya ölmedi. Aç kaldı.'
- **bölümler:** hero (kavanoz) → üç ölümün sebebi → kavanoz günlüğü → fırın zamanı → kamera mutfakta kalır → yorum → fiyat → SSS
- **an:** Süreyi kaydırıp sıcaklığı değiştirince kavanozdaki mayanın kabarıp zirveye çıkması, sonra çökmesi
- **hero eskizi:**
```
[ kavanoz SVG     ][ Maya ölmedi.  ]
[ bant · lastik   ][ Aç kaldı.     ]
[ süre ────●──── ][ lede, CTA     ]
[ 19° 23° 27°    ][ (bant notu)   ]
```
