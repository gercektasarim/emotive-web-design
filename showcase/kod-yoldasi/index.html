public final class EftLimitValidator {
    private static final LocalTime EFT_KAPANIS = LocalTime.of(17, 0);

    public ValidationResult validate(TransferRequest req, Customer musteri) {
        if (req.amount().signum() <= 0) {
            return ValidationResult.reject("TUTAR_GECERSIZ");
        }
        // Günlük limit: bugünkü transferler + bu işlem
        BigDecimal bugun = transferRepo.sumToday(musteri.id(), req.currency());
        if (bugun.add(req.amount()).compareTo(musteri.dailyLimit()) > 0) {
            return ValidationResult.reject("GUNLUK_LIMIT_ASILDI");
        }
        return ValidationResult.ok();
    }
}

Bilgi güvenliği ekibiniz önce bunu soracak.

“Kod nereye gidiyor?” Cevap: hiçbir yere. Kod Yoldaşı ağ bağlantısı açmayan, imzalı bir eklenti ve yerel bir model dosyasından oluşur. Güncellemeler bile kurumun iç paket deposundan dağıtılır.

BDDK bilgi sistemleri düzenlemeleri, iç denetim ve kaynak kod politikaları açısından değerlendirmeniz için ağ trafiği kaydı, yazılım malzeme listesi (SBOM) ve model kartı pilotla birlikte gelir.

Geliştiricilerin sorduğu

Bilgisayarım yeterli mi?

32 GB bellekli Apple Silicon ya da 8 GB ekran kartlı bir Windows/Linux dizüstü rahat çalışır. 16 GB’de daha küçük model ile tamamlama yapılır, test yazma yavaşlar.

Bizim kodumuzla eğitiliyor mu?

Hayır. Model kurumunuzun koduyla eğitilmez. Projeyi yalnız öneri bağlamı için yerel olarak dizinler; dizin bilgisayardan çıkmaz ve silinebilir.

Ürettiği kodun lisansı?

Model, lisansı izin veren açık kaynak kodla eğitildi; uzun ve birebir eşleşen önerileri filtreler. Üretilen kodun hakları kurumunuza aittir.

Hangi diller?

Java, Kotlin, C#, Python, TypeScript, Go, SQL ve PL/SQL güçlü; COBOL ve RPG için açıklama ve okuma desteği.
