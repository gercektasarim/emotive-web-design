# Odak Taşı — tasarım notları

**Fiziksel dünya:** Gündüz masası; 23 sekme, yarım bırakılmış KDV beyannamesi, kenara yapıştırılmış sarı not, avuçta tutulan pürüzsüz dere taşı (kaygı taşı). Ritüel: dağılmak, sonra geri dönmek.
**Geliş → çıkış:** Yirmi sekme açık, üç işi yarım, kendine kızan yetişkin → kendine şefkatli, toparlanmış.

## Yön taslakları

**A · Masaüstündeki taş** (seçildi)
- Palet: #F1F0EB masa · #2B2E33 kurşun kalem · #8E918A dere taşı · #F4D65E yapışkan not · #4C6B57 taş yosunu (geri dönüş)
- Tipografi: Bricolage Grotesque (karakterli, sıcak başlık) + Atkinson Hyperlegible (DEHB/disleksi için okunaklı gövde)
- Tempo: orta-sıkı, ürün arayüzü yoğunluğu (admin kalıbı); sola hizalı
- Doku: düz pencere, 2px kurşun çizgi, taş biçimli hatırlatma balonu
- Hareket: tek an, "23 sekmeyi işlere göre topla"
- Ses: "sen", suçlamayan, somut ("Üç alan kaldı")
- Bölümler: hero (gerçek masaüstü) → başka yerde duyduğun / burada duyduğun → bir salı zaman çizelgesi → ekran gizliliği → söz → SSS → fiyat
- An: sekmelerin üç iş yığınına toplanması
```
Dağıldın. Sorun değil.          DEHB'li yetişkinler için...
Kaldığın yer burada.            [Mac] [Windows]
[o o o | GİB | Gelen | Bodrum | Excel | ... 23 sekme ]
| KDV formu, 3 boş alan        | (taş) Beyanname seni bekliyor |
|                              | [Oraya dön] [Yarım saat sonra] |
```
