# Sükût — tasarım notları

**Fiziksel dünya:** Toplantı odası; koyu yün takım, ceviz masa, kolda saat, bronz kuron. Işık: floresan değil, öğleden önce camdan gelen gri ışık. Tempo: bir saatlik toplantının içindeki kırk saniye.
**Geliş → çıkış:** İş toplantılarında öfkesini tutamamaktan yorulmuş, kanıt arayan yönetici → yatışmış; "bunu kimse fark etmeden yapabilirim".

## Yön taslakları

**A · Bilekteki dokunuş** (seçildi)
- Palet: #202326 yün takım · #E3E4E1 masa grisi · #8FA9BA nefes çeliği · #C9A86E saat kuronu · #D08A63 yükselen ton (yalnız grafik)
- Tipografi: Instrument Serif (yönetim kurulu ağırbaşlılığı, ince) + Public Sans (rapor gövdesi)
- Tempo: geniş, koyu/açık bant dönüşümü; sola hizalı
- Doku: düz yüzey, gölge yalnız saatte; fotoğraf yok
- Hareket: tek an, saatteki genişleyip daralan nefes halkası (90 sn)
- Ses: "siz", kısa, kanıtlı ("Söz o sırada başkasındaydı. Fark eden olmadı.")
- Bölümler: hero(saat) → bir toplantının grafiği → bilek/ekran/kulak → saklanan/saklanmayan defter → haftalık özet → yönetici sözü → fiyat+SSS
- An: hero'daki saatte 90 saniyelik nefes denemesi
```
[Sükût]                     [Bir toplantı][Ne saklanır][İndir]
Sesiniz yükselmeden önce,        ( saat kadranı )
doksan saniye.                   ( 10:47 · Nefes )
[iPhone+Watch] [Android]         ( 104 nabız +18% )
Ses kaydı yok · ₺690          Doksan saniyeyi burada deneyin
```

**B · Yönetim kurulu raporu** — kâğıt rapor estetiği, beyaz zemin, tablo ve dipnot; hero bir "çeyrek öfke raporu". Palet kâğıt beyazı + lacivert + bordo. Ses kurumsal, mesafeli.

**C · Sessiz koridor** — toplantıdan çıkıp koridorda verilen 90 saniye; adaçayı/taş tonları, çok boşluk, spa dili. Kategori (wellness) varsayılanına çok yakın.

## Revizyonlar
- Palet/doku: açık bölümlerin kremi toplantı masasının mat grisine (#E3E4E1) çekildi, grafik ve defter kenarlıkları soğutuldu.
- Varsayılan: başlıktaki gri italik vurgu kaldırıldı.
- Mobil: kadran metinleri küçültüldü, nabız/ton satırı halkanın altına indirildi; grafik etiketleri büyütüldü.
